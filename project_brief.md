# My agent: ChefGemini (Personal Chef & Meal Planner)
One-liner: A conversational agent that helps home cooks plan meals, discover recipes, and balance nutrition with a catalog of custom recipes and ingredients.

Tool coverage:
- Memory: Remembers dietary restrictions (e.g. vegan, gluten-free), allergies, disliked ingredients, kitchen equipment, and past meal ratings across sessions.
- Tools: Searches recipe catalog by pantry ingredients/constraints, logs consumed meals, and checks nutritional information.
- Catalog/UI: Recipe cards (prep time, difficulty, ingredients list) and weekly meal plan summary tables rendered via A2UI.
- Image gen: Generates mouth-watering plating and food presentation visuals for suggested recipes.
- Sandbox: Calculates calorie breakdowns, macro splits (protein/carb/fat), and recipe scaling/unit conversions.

Recommended for every project: memory, storage, tools, image generation, A2UI
Agent-specific / stretch (pick what fits): Code sandbox for macro/nutrition calculations, grocery delivery or Maps API for ingredient sourcing.
